The Time Traveler's Code

Embark on an epic journey to recover the fragments of time!

Step into the reality

The year is 3024. The world's first time machine, "Chronos Mark IX," has suffered a catastrophic failure.

The core algorithm, "The Code of Eternity," has fragmented and dispersed across key moments in history.

Your mission is to become a "Chrono-Tracker" and restore balance to the timeline before it's too late.

Event Flow

  • Prologue

    Objective: Decode the activation key using a visual puzzle embedded with a QR code leading to the next stage.

  • The Ancient Era

    Challenge: Decode hieroglyphics representing a Caesar cipher encrypted clue. Teams must also solve a basic riddle about Egyptian mythology.

  • The Renaissance

    Crack a puzzle embedded in Da Vinci’s sketches. It involves solving an anagram and creating a Python script for matrix-based cryptography

  • The Industrial Age: Code in the Coal Mines

    Challenge: Decrypt a Morse code message hidden in a simulated coal mine audio file.

  • World War II: Enigma Redux

    Challenge: Solve an Enigma-inspired cryptography puzzle. Teams must collaborate to run a simulation of an Enigma machine using online tools or Python libraries.

  • The Digital Revolution

    Challenge: Identify and debug errors in a code snippet causing an e-commerce website to malfunction.

  • The Quantum Era: Schrödinger’s Key

    Challenge: Solve a puzzle based on quantum mechanics principles. Use Python's Qiskit library to simulate a quantum gate.

  • Epilogue: Stabilizing the Timeline

    Final Challenge: Combine all the retrieved fragments into a single Python program that simulates the time machine's restoration process.
